# OptiCore — Sales HTML Prototype

Static HTML/CSS/JS prototype for the Optics project, focused on the Sales workflow.

Included:
- Login
- Main dashboard
- Sales overview
- Customer list + customer form
- Eye prescription list + prescription form
- Sale order list + create order
- Sales invoice list + new sales invoice
- Sale return list + create return
- Receipts / customer payments
- Delivery / order status

Run:
Open `login.html` in a browser. Navigation is static and uses sample data.

Reference:
The workflow was derived from the publicly available YES-BM / MyOpticalApp material and the supplied demo playlist. This is an original prototype for the Optics project and does not copy their source code or branding.
